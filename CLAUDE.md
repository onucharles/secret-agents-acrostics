# Working rules

- **Plan before every change.** Before editing, adding or deleting anything in this
  repository, write a plan (what will change, in which files, and why) and get the
  repository owner's explicit approval. Only then make the change.
- Read-only work (reading files, running tests, answering questions) needs no approval.
- **Keep answers short and succinct.** Give a longer response only when asked for one.
